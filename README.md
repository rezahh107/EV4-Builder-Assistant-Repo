## Role

Builder executes proven Elementor actions. Architect owns architecture. CE owns constructability proof. Builder does not redesign, rescore, or infer missing decisions.

## Personal Quick Start

```text
شروع
→ upload `builder-input.json`
→ run local Builder Inspector
→ upload matching `builder-intake-authorization.json`
→ enter APPROVED_HANDOFF_MODE / BUILD_ACTIVE only when accepted and matching
→ emit the first authorized Builder batch
```

The filename is only an operator hint. Semantic acceptance depends on parsed content, official Schema/cross-field/lineage validation, exact byte identity, canonical package digest, selected candidate, and the accepted personal intake capsule.

Create the capsule:

```bash
node scripts/builder-inspector.mjs intake \
  --input builder-input.json \
  --output builder-intake-authorization.json
```

Verify it later:

```bash
node scripts/builder-inspector.mjs verify-capsule \
  --input builder-input.json \
  --capsule builder-intake-authorization.json
```

`project-gate-c2b-receipt.json` is optional audit evidence and never Builder semantic input. Raw `ce-project-gate.json` is not manually unpacked.

## Resume

A new chat resumes only from matching uploaded carriers and an accepted local resume authorization:

```bash
node scripts/builder-inspector.mjs resume \
  --input builder-input.json \
  --capsule builder-intake-authorization.json \
  --state-capsule builder-personal-state.json \
  --session-state session-state.json \
  --checkpoint checkpoint.json \
  --output builder-resume-authorization.json
```

`استارت` never creates a new session. Session, exact input bytes, package digest, candidate, Checkpoint, Session State, blockers, and transition legality must match.

## Builder Completion

Builder-only completion is validated locally with the final state carriers, Completion Status, and Completion Gate. It does not imply Responsive completion or production readiness.

```bash
node scripts/builder-inspector.mjs completion \
  --input builder-input.json \
  --capsule builder-intake-authorization.json \
  --previous-state-capsule previous-state.json \
  --state-capsule final-state.json \
  --session-state final-session-state.json \
  --checkpoint final-checkpoint.json \
  --completion-status completion-status.json \
  --completion-gate completion-gate.json \
  --output builder-completion-authorization.json
```
