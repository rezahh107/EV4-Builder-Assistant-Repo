## Personal Authorization

Canonical personal execution requires exact matching:

```text
builder-input.json
builder-intake-authorization.json
```

The capsule is generated by local `scripts/builder-inspector.mjs`. The model only compares supplied identity fields and never claims it ran validators or recomputed hashes.

No accepted matching capsule means `START_INTAKE_MODE / EVIDENCE_REQUIRED`, no batch, and one local Inspector command.

Receipt-only, raw Project Gate envelopes, manual nested extraction, silent direct Adapter invocation, filename-only acceptance, and package-prose execution are forbidden.

## Resume and State
